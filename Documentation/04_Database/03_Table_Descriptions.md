# Table Descriptions

## Introduction

This document describes the purpose and key attributes of each database table used in the ThreatLens AI system.

---

# 1. Users

## Purpose

Stores user account information and authentication details.

| Field | Data Type | Description |
|--------|-----------|-------------|
| user_id | INT | Unique user identifier (Primary Key) |
| name | VARCHAR(100) | User's full name |
| email | VARCHAR(100) | User email address |
| password | VARCHAR(255) | Encrypted password |
| role | VARCHAR(50) | User role |
| created_at | TIMESTAMP | Account creation date |

---

# 2. Uploaded_Files

## Purpose

Stores information about uploaded executable files.

| Field | Data Type | Description |
|--------|-----------|-------------|
| file_id | INT | Unique file identifier (Primary Key) |
| user_id | INT | Uploaded by (Foreign Key) |
| file_name | VARCHAR(255) | Name of uploaded file |
| file_hash | VARCHAR(255) | SHA-256 hash |
| file_size | BIGINT | File size |
| upload_date | TIMESTAMP | Upload timestamp |

---

# 3. Analysis_Results

## Purpose

Stores static malware analysis results.

| Field | Data Type | Description |
|--------|-----------|-------------|
| analysis_id | INT | Primary Key |
| file_id | INT | Foreign Key |
| md5_hash | VARCHAR(255) | MD5 hash |
| sha256_hash | VARCHAR(255) | SHA-256 hash |
| metadata | JSON | File metadata |
| pe_header | JSON | PE header details |
| strings | TEXT | Extracted strings |

---

# 4. YARA_Results

## Purpose

Stores YARA rule scan results.

| Field | Data Type | Description |
|--------|-----------|-------------|
| yara_id | INT | Primary Key |
| file_id | INT | Foreign Key |
| rule_name | VARCHAR(100) | Matched rule |
| match_status | VARCHAR(20) | Match result |
| detection_time | TIMESTAMP | Scan time |

---

# 5. ML_Predictions

## Purpose

Stores machine learning prediction results.

| Field | Data Type | Description |
|--------|-----------|-------------|
| prediction_id | INT | Primary Key |
| file_id | INT | Foreign Key |
| malware_family | VARCHAR(100) | Predicted malware family |
| confidence_score | FLOAT | Prediction confidence |
| risk_score | FLOAT | Threat risk score |
| prediction_date | TIMESTAMP | Prediction timestamp |

---

# 6. Reports

## Purpose

Stores generated malware analysis reports.

| Field | Data Type | Description |
|--------|-----------|-------------|
| report_id | INT | Primary Key |
| file_id | INT | Foreign Key |
| report_name | VARCHAR(255) | Report name |
| generated_date | TIMESTAMP | Report generation date |
| report_status | VARCHAR(20) | Report status |

---

# 7. Alerts

## Purpose

Stores threat alerts generated by the system.

| Field | Data Type | Description |
|--------|-----------|-------------|
| alert_id | INT | Primary Key |
| file_id | INT | Foreign Key |
| severity | VARCHAR(20) | Threat severity |
| alert_type | VARCHAR(100) | Alert category |
| status | VARCHAR(20) | Alert status |
| created_at | TIMESTAMP | Alert creation time |

---

# 8. Audit_Logs

## Purpose

Stores user activity logs.

| Field | Data Type | Description |
|--------|-----------|-------------|
| log_id | INT | Primary Key |
| user_id | INT | Foreign Key |
| activity | TEXT | User activity |
| timestamp | TIMESTAMP | Activity time |
| status | VARCHAR(20) | Activity status |

---

# Table Summary

| Table | Purpose |
|--------|---------|
| Users | User account management |
| Uploaded_Files | Store uploaded executable files |
| Analysis_Results | Static malware analysis results |
| YARA_Results | Signature detection results |
| ML_Predictions | AI prediction results |
| Reports | Malware analysis reports |
| Alerts | Threat alerts |
| Audit_Logs | User activity logs |
