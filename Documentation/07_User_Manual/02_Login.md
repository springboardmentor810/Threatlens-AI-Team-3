# User Login Guide

## Introduction

The Login module provides secure access to the ThreatLens AI system. Only authorized users with valid credentials can access the application and perform malware analysis.

---

# Login Steps

### Step 1

Open the application in your web browser.

```
http://localhost:5173
```

---

### Step 2

The Login page appears.

Enter the following credentials:

- Email Address
- Password

---

### Step 3

Click the **Login** button.

---

### Step 4

The system validates the credentials.

If authentication is successful, the user is redirected to the Dashboard.

---

# Login Screen

The Login page contains:

- Email Address
- Password
- Login Button
- Forgot Password (Optional)
- Error Messages

---

# Successful Login

After successful authentication, the user can:

- View Dashboard
- Upload Malware Samples
- Start Malware Analysis
- View Reports
- Monitor Alerts
- Access Analytics

---

# Failed Login

Possible reasons:

- Invalid Email
- Incorrect Password
- Unauthorized User
- Server Error

The system displays an appropriate error message.

---

# Security Features

- JWT Authentication
- Password Encryption
- Role-Based Access Control (RBAC)
- Session Management
- Secure Logout

---

# Best Practices

- Use a strong password.
- Do not share login credentials.
- Always logout after completing your work.
- Report suspicious login activity to the administrator.

---

# Login Workflow

1. Open Login Page.
2. Enter Email and Password.
3. Click **Login**.
4. System verifies credentials.
5. Dashboard is displayed upon successful authentication.

---

# Summary

The Login module ensures that only authenticated users can access the ThreatLens AI platform while protecting user accounts through secure authentication and authorization mechanisms.
