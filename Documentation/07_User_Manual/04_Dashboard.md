# Dashboard Guide

## Introduction

The Dashboard is the central interface of the ThreatLens AI system. It provides users with a comprehensive overview of malware analysis results, security alerts, threat statistics, and recent system activities.

---

# Dashboard Overview

After successful login, users are redirected to the Dashboard, where they can monitor system activities and access key features.

---

# Dashboard Components

## 1. Summary Cards

The dashboard displays key statistics such as:

- Total Files Analyzed
- Malware Detected
- Clean Files
- High-Risk Threats
- Pending Analysis

---

## 2. Recent Analysis

Displays recently analyzed files with details including:

- File Name
- Malware Family
- Risk Score
- Analysis Date
- Analysis Status

---

## 3. Threat Statistics

Provides graphical insights into:

- Malware Distribution
- Detection Trends
- Malware Families
- Risk Levels

---

## 4. Alerts Panel

Displays:

- Active Alerts
- High-Risk Malware
- Recent Security Notifications
- Alert Status

---

## 5. Reports Section

Users can:

- View Reports
- Search Reports
- Download Reports
- Export Reports

---

# Dashboard Workflow

1. User logs in.
2. Dashboard loads summary statistics.
3. Recent malware analyses are displayed.
4. Active alerts are shown.
5. Users can navigate to Reports, Analytics, or Upload modules.

---

# Features

- Real-time Dashboard
- Malware Statistics

- Recent Activity

# Best Practices

- Review the dashboard regularly.
- Monitor high-risk alerts.
- Analyze newly uploaded files promptly.
- Download reports for future reference.
- Monitor malware trends for security insights.

# Summary

The Dashboard provides a centralized view of malware detection, threat monitoring, reports, and security analytics, enabling users to efficiently monitor and manage cybersecurity events.
